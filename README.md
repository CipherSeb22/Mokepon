Propósito: desarrollar un juego interactivo aplicando diferentes conceptos de programación web.
Estado: funcional, actualmente con mejoras visuales pendientes.
Aprendizaje/reflexión: además de conseguir que las funcionalidades principales operaran correctamente, el proyecto me permitió comprender que el desarrollo de software no termina cuando una aplicación funciona; la experiencia del usuario, la organización visual y los detalles de interfaz también forman parte importante de un producto completo.
